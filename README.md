\# LibraGuide AI



LibraGuide AI is a locally hosted academic library research assistant developed with Streamlit, Ollama, Qwen3, EmbeddingGemma and SQLite.



\## Current capabilities



\- General academic library and research assistance

\- Retrieval-augmented generation from approved PDF documents

\- Filename and page citations

\- Administrator-controlled document management

\- Local user registration and authentication

\- Consent-based personalisation preferences

\- User-specific saved conversations

\- Moderated feedback and correction workflow

\- Librarian-verified knowledge notes

\- Local persistent storage using SQLite



\## Technology



\- Python 3.11

\- Streamlit

\- Ollama

\- Qwen3 4B

\- EmbeddingGemma

\- SQLite

\- NumPy

\- PyPDF

\- Requests
